# Логика презентации BuildWatch

Версия: 28 сентября 2026 года. Регламент защиты: 10 минут.

Презентация строится вокруг одного маршрута инспектора: **карта портфеля → выбранный объект → объяснимый сигнал → проверка → пилот**. Сначала идут пять слайдов по обязательному блоку шаблона ЛЦТ2026, затем семь визуальных слайдов. Скриншоты главного экрана и сравнения плана с наблюдением сняты с локально запущенного интерфейса 28 сентября; данные синтетического демо-портфеля.
